# Tutor Ledger

**A free, offline Android app for private tutors.**

Manage lessons, students, attendance and payments in one place — without subscriptions, ads or accounts. **All features are free, with no limits on students or classes.**

**[Download the latest APK](https://github.com/ilyakhaiko/TutorLedger/releases/latest)**

## Features

- **Students and classes:** manage individual students, groups and archived records.
- **Lesson planning:** weekly calendar, recurring schedules and one-off lessons.
- **Attendance:** track completed, missed and cancelled lessons.
- **Payments:** record payments, adjustments and outstanding balances.
- **Reports:** review monthly activity and payment summaries.
- **Reminders and widgets:** upcoming lessons at a glance.
- **Backups:** export and import your data, with additional in-app backups.
- **Personalization:** light and dark themes, flexible navigation and display settings.

## Download and install

1. Open **[Releases](https://github.com/ilyakhaiko/TutorLedger/releases/latest)**.
2. Download `TutorLedger-v1.3.3.apk` (or the APK from the latest release).
3. Open the APK on your Android device. Android may ask you to allow installation from your browser or file manager.

The release also includes a `.sha256.txt` file so you can verify the APK's integrity. On Windows, run `Get-FileHash .\TutorLedger-v1.3.3.apk -Algorithm SHA256` in PowerShell and compare the result with the checksum file.

**Important when switching from the Google Play version:** Export a **manual JSON backup** and store it outside the app *before* uninstalling anything. The GitHub APK may use a different signing certificate and might not install over the Play version. If Android rejects the update, keep your backup safe, uninstall the old version, install the GitHub APK, and import your data. Uninstalling removes the app's local database and internal backups.

## Privacy and offline use

Tutor Ledger works **entirely offline**. It does not require an account, cloud service or internet connection for normal operation. Your records remain on your device. There are no ads, analytics or in-app purchases.
